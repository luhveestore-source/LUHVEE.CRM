💖 LuhVee CRM + Automação de Vendas
📌 Descrição do Projeto
O LuhVee CRM é um sistema 100% online e gratuito desenvolvido para automatizar o processo de captação de leads, organização de clientes e vendas da loja LuhVee Stores Shoes 👠✨.
O sistema funciona como um mini CRM inteligente focado em moda feminina e e-commerce, permitindo transformar visitantes em clientes através de automação simples e eficiente.
🚀 O que o sistema faz automaticamente
💬 1. Captura de Leads
Registra nome, WhatsApp, e-mail e interesse do cliente
Organiza automaticamente em uma base de dados
Permite visualizar todos os leads em tempo real
👠 2. Segmentação de Interesse
Classifica clientes por categoria:
Sapatos
Botas
Scarpin
Sandálias
Facilita campanhas direcionadas e vendas mais assertivas
🤖 3. Automação de Mensagem (WhatsApp)
Gera mensagem pronta automática para envio
Direciona o cliente para atendimento via WhatsApp
Aumenta conversão com abordagem rápida e personalizada
📊 4. Painel de Controle (CRM)
Visualização de todos os leads cadastrados
Lista organizada em tempo real
Interface simples e rápida para gestão
🌐 5. Sistema Online Gratuito
Funciona diretamente na nuvem
Acesso via link público
Hospedado via Streamlit Cloud + GitHub
Sem necessidade de servidor pago
💖 6. Foco em Vendas da LuhVee
O sistema foi criado especialmente para:
Loja de sapatos femininos
Moda e achadinhos
Campanhas no Instagram e WhatsApp
Funil simples de conversão
🔥 Objetivo Final
Transformar a LuhVee Stores em uma loja automatizada, onde:
Leads entram automaticamente
Clientes são organizados sozinhos
Mensagens de venda são prontas
O WhatsApp vira canal principal de conversão
A dona foca apenas em vender e postar conteúdo
⚙️ Tecnologias Utilizadas
Streamlit (interface web)
Python (lógica do sistema)
Pandas (organização de dados)
GitHub (versionamento)
Streamlit Cloud (deploy gratuito)
💡 Visão do Projeto
Este sistema é o primeiro passo para transformar a LuhVee Stores Shoes em uma marca digital automatizada, escalável e independente de grandes plataformas pagas.
